# @sparkyidea/dataview-drizzle

PostgreSQL query builders for [Ocean DataView](https://ocean-dataview.sparkyidea.com) on Drizzle ORM: turn DataView filters, sorts, groups, and rollups into SQL. PostgreSQL only.

```bash
npm install @sparkyidea/dataview-drizzle@alpha @sparkyidea/dataview-core@alpha drizzle-orm
```
