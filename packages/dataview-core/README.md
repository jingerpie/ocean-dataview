# @jingerpie/dataview-core

Framework-neutral core of [Ocean DataView](https://ocean-dataview.sparkyidea.com): property and query types, validators, URL codecs, and transport schemas. No React.

```bash
npm install @jingerpie/dataview-core@alpha zod date-fns chrono-node
```

See the [installation guide](https://ocean-dataview.sparkyidea.com/docs/data-view/installation).
