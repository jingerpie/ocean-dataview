# @jingerpie/dataview-react

Headless React providers and hooks for [Ocean DataView](https://ocean-dataview.sparkyidea.com). The styled components install from the shadcn registry.

```bash
npm install @jingerpie/dataview-react@alpha @jingerpie/dataview-core@alpha @tanstack/react-query
npm install nuqs # optional: URL state via @jingerpie/dataview-react/nuqs
```

See the [installation guide](https://ocean-dataview.sparkyidea.com/docs/data-view/installation).
