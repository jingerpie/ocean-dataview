---
title: Installation
description: Install the headless packages from npm and the styled components from the shadcn registry
---

Ocean DataView ships in two parts:

- **npm packages** hold the logic. You update them with a version bump.
- **A shadcn registry** holds the styled components. `shadcn add` copies their source into your app, and you own and restyle it.

## Requirements

- React 19 with Tailwind CSS 4.
- A shadcn project using the `base-nova` style (Base UI primitives). Run `npx shadcn@latest init` first if you have no `components.json`.
- TanStack Query 5, with a `QueryClientProvider` above your views.
- Optional: `nuqs` 2.8+ to keep view state in the URL.

## 1. Install the packages

```bash
npm install @jingerpie/dataview-core@alpha @jingerpie/dataview-react@alpha @tanstack/react-query
# Optional: URL state
npm install nuqs
# Server: PostgreSQL query builders for Drizzle ORM
npm install @jingerpie/dataview-drizzle@alpha drizzle-orm
```

## 2. Add components

```bash
npx shadcn@latest add https://ocean-dataview.sparkyidea.com/r/table-view.json
npx shadcn@latest add https://ocean-dataview.sparkyidea.com/r/notion-toolbar.json
```

Each item pulls in what it needs: other DataView items, stock shadcn primitives, npm packages, and the `dataview-styles` colour tokens (added to your CSS file for light and dark mode).

Files land under your `components.json` aliases. With the default aliases:

| Item files | Destination |
|------------|-------------|
| Views, toolbar, editors | `components/dataview/...` |
| Customized primitives | `components/ui/dataview-*.tsx` (they never overwrite your `button.tsx` and others) |
| Helpers | `lib/dataview/...` |
| DOM hooks | `hooks/dataview/...` |

Nested folders are kept as long as your `components` alias ends in a `components` directory (for example `@/components` or `@/shared/components`).

To pin a release, use the versioned URLs, for example `https://ocean-dataview.sparkyidea.com/r/0.1.0-alpha.0/table-view.json`.

## 3. Use them

```tsx
"use client";

import { DataViewContent, DataViewProvider, usePageController } from "@jingerpie/dataview-react";
import { useNuqsDataViewState } from "@jingerpie/dataview-react/nuqs";
import { NotionToolbar } from "@/components/dataview/toolbars/notion/toolbar";
import { TableView } from "@/components/dataview/views/table-view/table-view";

export function Products() {
  const state = useNuqsDataViewState();
  const { controller } = usePageController({
    dataQuery: (params) => trpc.product.getMany.queryOptions(params),
  });

  return (
    <DataViewProvider controller={controller} properties={productProperties} state={state}>
      <div className="flex flex-col gap-2">
        <NotionToolbar enableSettings />
        <DataViewContent>
          <TableView pagination="page" />
        </DataViewContent>
      </div>
    </DataViewProvider>
  );
}
```

See [Provider](/docs/data-view/provider) for state options and [Table View](/docs/data-view/views/table) for view props. The copied components are yours: edit their markup and classes freely. Logic updates arrive through the npm packages.
