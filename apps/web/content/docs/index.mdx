---
title: Ocean DataView
description: A React data view system for building Notion-style interfaces.
---

Ocean DataView provides pre-built data views (Table, List, Gallery, Board) with a unified property schema, URL or controlled state management, and Notion-inspired UX.

## Documentation

- [Installation](/docs/data-view/installation) - npm packages plus `shadcn add` for the components
- [Property Schema](/docs/data-view/properties/schema) - Define your data schema with 13 property types
